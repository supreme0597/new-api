## 1. 账号注册与登录

### 1.1 注册账号

如果管理员开放了注册，在登录页点击"注册"，填写：

| 字段 | 说明 |
|------|------|
| 用户名 | 登录用，不超过 20 个字符 |
| 密码 | 8-20 个字符 |
| 邮箱 | 用于找回密码和接收通知（可能需要验证） |

### 1.2 登录方式

系统支持以下登录方式（取决于管理员配置）：

| 方式 | 说明 |
|------|------|
| 密码登录 | 输入用户名和密码 |
| Passkey / 生物识别 | 使用指纹、面部等无密码登录 |
| GitHub 登录 | 使用 GitHub 账号授权登录 |
| Discord 登录 | 使用 Discord 账号授权登录 |
| OIDC 登录 | 使用企业 OIDC 统一认证 |
| 微信登录 | 使用微信扫码登录 |
| Telegram 登录 | 使用 Telegram 账号登录 |
| LDAP 登录 | 企业员工使用工号和 LDAP 密码登录 |

#### LDAP 登录说明

如果企业开启了 LDAP 认证：

1. 在登录页勾选或选择"LDAP 登录"
2. 输入工号作为用户名
3. 输入 LDAP 密码（与企业的 LDAP/AD 密码一致）
4. 首次登录会自动创建账号

### 1.3 找回密码

在登录页点击"忘记密码"，输入注册邮箱，系统会发送重置密码邮件。按照邮件指引完成重置。

### 1.4 退出登录

点击页面右上角头像 → **退出登录**。

## 3. API 密钥管理

路径：**密钥管理**

API 密钥（Token）是调用 AI 接口时的凭证。每个用户可以创建多个密钥，用于不同的应用场景。

### 3.1 创建密钥

点击"添加密钥"，填写：

| 字段 | 说明 |
|------|------|
| 名称 | 密钥的备注名称，便于识别用途 |
| 额度 | 该密钥的额度上限（留空则使用账户余额） |
| 无限额度 | 勾选后该密钥不消耗额度 |
| 过期时间 | 密钥的到期时间（留空永不过期） |
| 模型限制 | 限制该密钥只能调用指定模型 |
| 允许 IP | 限制只有指定 IP 可以使用该密钥（多个 IP 用逗号分隔） |
| 分组 | 密钥所属分组（不填则跟随用户分组） |

### 3.2 密钥格式

创建完成后，系统会生成以 `sk-` 开头的密钥字符串，例如：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**请立即复制并保存**，关闭对话框后将不再显示完整密钥。

### 3.3 管理密钥

| 操作 | 说明 |
|------|------|
| 查看密钥列表 | 显示所有密钥（密钥值已脱敏） |
| 查看密钥完整值 | 点击"查看"按钮后需要安全验证 |
| 编辑密钥 | 修改名称、额度限制、模型限制等 |
| 启用/禁用 | 临时停用某个密钥 |
| 删除密钥 | 永久删除 |

### 3.4 LDAP 工号令牌

如果企业开启了 LDAP 认证，工号可以直接作为 API 密钥使用：

```
Authorization: Bearer <工号>
LDAP-Password: <LDAP密码>
```

首次使用系统会自动创建对应的令牌（名称为"LDAP 工号令牌"），后续请求使用相同工号会直接复用令牌，无需重复 LDAP 查询。

> **提示**：LDAP 工号令牌自动创建后，你可以在 **密钥管理** 页面找到该令牌，点击"编辑"按钮进入编辑界面。
> 在编辑界面的高级设置中，可以设置 **允许 IP** 白名单（多个 IP 用逗号分隔），限制只有指定的 IP 地址才能使用该令牌，进一步提升安全性。

#### 3.4.1 典型场景：内部专有模型访问

> 管理员创建了一个内部专用分组和对应渠道，并将你分配到这个分组。你可以通过 LDAP 工号令牌直接访问这些专有模型，无需额外配置。

**场景说明**：
管理员会创建一个不对普通用户公开的分组（例如 `internal-ai`），并在此分组下配置专门的渠道和模型。被授权的用户（分组设为 `internal-ai`）可以通过 LDAP 工号令牌正常访问这些模型。

**访问方式**：
与普通 LDAP 令牌调用完全一致，无需特殊操作：

```bash
curl https://您的域名/v1/chat/completions \
  -H "Authorization: Bearer <您的工号>" \
  -H "LDAP-Password: <LDAP密码>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

**如何判断自己有哪些可用模型**：

1. 打开**模型列表**页面，查看所有可用的模型
2. 如果你被分配到了 `internal-ai` 分组，该分组下的专有模型会显示在列表中
3. 在**我的渠道**页面中，如果渠道归属给你，你也可以看到和管理对应渠道

**权限说明**：

| 项目 | 说明 |
|------|------|
| 我的分组 | 由管理员设置，可在**个人主页**查看 |
| 可用模型 | 取决于你的分组对应的渠道配置 |
| 模型广场可见性 | 你能看到所有你有权限使用的模型 |
| 未授权的用户 | 看不到此分组下的任何模型和渠道信息 |

> **注意**：如果你调用某个模型时返回 404 或权限错误，说明你的分组没有该模型的访问权限。请联系管理员调整分组。

### 3.5 安全建议

- 为不同应用创建不同的密钥，避免一个泄露导致全部受影响
- 设置 IP 限制，防止密钥被异地盗用
- 设置模型限制，防止密钥被用于非预期的模型
- 定期轮换密钥

## 4. 额度说明

额度（Quota）是系统中使用 API 的计费单位。每次调用 AI 接口会按照模型费率消耗额度。

**查看额度**：
- 页面顶部导航栏会显示当前可用额度
- 在个人主页可以看到额度记录

**额度消耗查询**：路径 **使用日志** → 查看每次请求消耗的额度明细

## 6. 调用 API

### 6.1 API 地址

```
https://您的域名/v1
```

兼容 OpenAI API 格式，可直接使用 OpenAI SDK 接入。

### 6.2 认证方式

在请求头中提供 API 密钥：

```
Authorization: Bearer sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 6.3 支持的标准接口

#### 聊天补全 （Chat Completions）

```bash
curl https://您的域名/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

#### 文本补全 （Completions）

```bash
curl https://您的域名/v1/completions \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-3.5-turbo-instruct",
    "prompt": "Once upon a time"
  }'
```

#### 嵌入向量 （Embeddings）

```bash
curl https://您的域名/v1/embeddings \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": "Hello world"
  }'
```

#### 模型列表

```bash
curl https://您的域名/v1/models \
  -H "Authorization: Bearer sk-xxx"
```

#### 图片生成 （Images）

```bash
curl https://您的域名/v1/images/generations \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "dall-e-3",
    "prompt": "A cute cat"
  }'
```

#### 音频接口

```bash
# 语音转文字
curl https://您的域名/v1/audio/transcriptions \
  -H "Authorization: Bearer sk-xxx" \
  -F "file=@audio.mp3" \
  -F "model=whisper-1"

# 文字转语音
curl https://您的域名/v1/audio/speech \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1",
    "input": "Hello world",
    "voice": "alloy"
  }'
```

### 6.4 非标准接口

#### Claude API

```bash
curl https://您的域名/v1/messages \
  -H "Authorization: Bearer sk-xxx" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-20250514",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

#### Gemini API

```bash
curl https://您的域名/v1beta/models/gemini-2.0-flash:generateContent \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"parts":[{"text": "Hello"}]}]
  }'
```

#### Midjourney API

```bash
curl https://您的域名/mj/submit/imagine \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "a beautiful landscape"
  }'
```

#### Suno API（音乐生成）

```bash
curl https://您的域名/suno/v1/generate \
  -H "Authorization: Bearer sk-xxx" \
  -H "Content-Type: application/json"
```

### 6.5 使用 OpenAI SDK

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://您的域名/v1",
    api_key="sk-xxx"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)

print(response.choices[0].message.content)
```

```javascript
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://您的域名/v1',
  apiKey: 'sk-xxx',
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }],
});

console.log(response.choices[0].message.content);
```

## 8. 模型与渠道

### 8.1 模型列表

路径：**模型列表**

展示所有可用的模型及其信息：
- 模型名称和显示名称
- 提供商/供应商
- 能力标签（聊天、图片、音频等）
- 计费倍率

### 8.2 模型性能排名

路径：**模型排名**

系统会定期对模型进行性能采样，展示以下指标：

| 指标 | 说明 |
|------|------|
| 延迟（Latency） | 请求响应时间 |
| TTFT （Time to First Token）| 首 Token 响应时间 |
| TPS （Tokens Per Second）| 每秒生成 Token 数 |
| 综合评分 | 综合各指标的评分 |

你可以根据性能数据选择最优的模型和渠道。

### 8.3 我的渠道

**我的渠道** 页面展示所有公共渠道和你自己创建的私有渠道。在这里你可以查看和管理属于自己的渠道。

#### 8.3.1 创建私有渠道

点击 **添加我的渠道**，填写渠道信息即可创建属于自己的私有渠道。你创建的渠道默认为私有渠道，仅自己可见和管理。

创建私有渠道时需要填写：

| 字段 | 说明 |
|------|------|
| 名称 | 渠道名称 |
| 类型 | 选择对应的 AI 服务提供商 |
| 密钥 | 填写该提供商的 API 密钥 |
| 分组 | 渠道所属分组，决定哪些模型可以使用该渠道 |
| 模型 | 指定该渠道支持的模型 |
| 代理 | 可选，设置请求代理地址 |
| 速率限制 | 可选，限制调用频率 |
| 测试模型 | 可选，用于测试连通性的模型 |

> **提示**：私有渠道仅自己可见，其他用户无法看到或使用你创建的渠道。

#### 8.3.2 管理渠道

如果管理员将渠道分配给了你（渠道归属），或者你创建了私有渠道，均可在 **我的渠道** 页面进行操作：

- 查看渠道详情
- 测试渠道连通性
- 编辑渠道配置（名称、密钥、模型等）
- 设置渠道分组

### 8.4 定价页

路径：**定价**

查看系统支持的模型及对应的价格倍率信息。

## 9. 账号安全

### 9.1 双因素认证 （2FA）

路径：**个人主页 → 安全设置 → 双因素认证**

开启 2FA 后，登录时需要额外输入 TOTP 动态验证码。

**开启步骤**：
1. 点击"开启双因素认证"
2. 使用认证器应用（如 Google Authenticator、Authy）扫描二维码
3. 输入验证码确认
4. 保存备用恢复码（用于丢失设备时恢复账号）

### 9.2 OAuth 账号绑定

路径：**个人主页 → OAuth 绑定**

可以绑定第三方账号用于快捷登录：
- GitHub
- Discord
- 微信
- Telegram
- 其他自定义 OAuth 提供商

绑定后，下次可以直接使用第三方账号登录，无需输入密码。

### 9.3 Passkey 管理

路径：**个人主页 → 安全设置 → Passkey**

添加设备生物识别（指纹、面部识别等）用于无密码登录和敏感操作验证。

### 9.4 敏感操作验证

系统对敏感操作（如查看完整密钥、修改安全设置）会要求二次验证，确保账号安全。

### 9.5 签到

路径：**个人主页 → 签到**

每日签到可以获得额外额度奖励。签到奖励规则由管理员配置。

## 11. 常见问题

### Q1：如何选择不同的 AI 模型？

在发起 API 请求时，在请求体中的 `model` 字段指定模型名称。可用模型清单可以在**模型列表**页面查看。

### Q2：提示"额度不足"怎么办？

请联系管理员增加额度。

### Q3：如何查看还剩多少额度？

页面顶部导航栏会显示当前可用额度。

### Q4：API 密钥泄露了怎么办？

立即在**密钥管理**页面禁用或删除泄露的密钥，然后创建新的密钥。

### Q5：为什么某些模型不可用？

模型可用性取决于：
- 你的用户分组是否有权限
- 密钥的分组设置
- 管理员是否配置了对应模型和渠道
- 如关联了订阅，订阅的分组是否包含该模型

### Q6：LDAP 用户如何调用 API？

使用工号作为 API 密钥，同时需要提供 LDAP 密码：

```
Authorization: Bearer <工号>
LDAP-Password: <LDAP密码>
```

首次调用会自动创建令牌，后续调用可省略 LDAP-Password（如果令牌已存在）。

### Q7：支持流式输出吗？

是的，所有兼容的模型都支持流式输出（Stream），在请求中设置 `"stream": true` 即可。

### Q8：请求超时了怎么办？

- 检查网络连接
- 确认 API 地址是否正确
- 尝试使用较小上下文（减少 Token 数）
- 检查使用的模型是否支持你的请求

### Q9：如何确认 API 服务是否正常？

访问 `https://您的域名/api/status` 查看系统状态，或访问 `https://您的域名/api/status/test` 进行连通性测试（需要管理员权限）。

### Q10：可以同时使用多个密钥吗？

可以，系统支持一个账户创建多个密钥，每个密钥可以设置不同的额度限制、模型限制和 IP 限制，适用于不同的应用场景。
