功能概述

什么是「我的渠道」

渠道归属新概念

每个渠道都有明确的归属：

🌐 公共渠道 — owner_user_id = NULL
所有人可见，按规则共享使用

🔒 私有渠道 — owner_user_id = 用户ID
仅所有者可用，安全私密

🌐

平台统一管理
所有用户共享使用
管理员维护
🔒
私有渠道

密钥独立管理

👁

查看自己的渠道

登录后可在「我的渠道」页面查看所有私有渠道列表，了解渠道配置与状态

创建私有渠道

创建新渠道时，系统自动将其归属为当前用户，作为私有渠道管理

可编辑自己渠道的密钥、模型配置、优先级等参数，完全掌控

支持一键测试自己的渠道，验证配置正确性，快速排查问题

🔃

复制公共渠道

可复制公共渠道为自己的私有副本，基于已有配置快速创建

技术细节

智能选路机制

1
优先私有渠道
2
公共渠道兜底
3
按优先级排序
N
权重随机选择
🚀 优先级 Priority
按 priority DESC 降序选取最高优先级的渠道
🎲 权重 Weight
同优先级按 weight 加权随机 (weight + 10)
🔄 重试 Retry
retry=0 用最高；retry>0 用第 N 低优先级
🔑 亲和性
支持基于用户、Key、UA 的渠道亲和性缓存
