# 2026-05-07

## 控制台菜单页面布局优化（消除滚动条）

### 问题
控制台所有表格页面（channel/user/token/log/redemption/task/midjourney/model/deployment/subscription）存在两个问题：
1. 顶部有 `mt-[60px]` 多余留白 + CardPro descriptionArea 重复标题，导致表格区域被大幅下推
2. 页面有滚动条，分页被推到视口下方，用户以为没有分页

### 方案与改动

**第一步（5/6）：去掉留白和重复标题**
- 11 个控制台页面去掉 `mt-[60px]`，改为 `px-2`
- `/console/channel` 去掉外层重复 `<h1>` 标题
- Users/Tokens/Redemptions/Subscriptions 的 Description 组件去掉和侧栏重复的标题文字，只保留 CompactModeToggle

**第二步（5/7）：消除页面滚动条**
- `PageLayout.jsx` Content 区域加上 `boxSizing: 'border-box'`，让 padding 算在 height 内部，避免子元素 `h-full` 超出
- `index.css` 中 `.table-scroll-card` 从固定高度 `calc(100vh - 110px)` 改为 `flex: 1 1 auto; min-height: 0; overflow: hidden;`，让 CardPro 作为 flex item 自动占满父容器剩余高度
- 各 table 页面外层 div 加上 `h-full flex flex-col`，Banner 和 CardPro 在同一 flex column 中合理分配空间
- Card body 保持 `overflow-y: auto`，表格在卡片内部滚动，分页 footer 始终固定在底部可见

### 影响范围
仅影响使用 CardPro 的 10 个控制台表格页面。Dashboard 也加上 `h-full` 保持一致但不使用 CardPro。

### 结果
控制台表格页面整体不再出现滚动条，表格 tbody 内部可滚动，分页始终贴底可见。
