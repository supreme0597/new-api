## 2026-05-08

### 修复 TanStack Invariant failed 错误
- 错误堆栈涉及 `useSyncExternalStoreWithSelector` 三层嵌套（React 19 内置 → polyfill → TanStack）
- 根因：`@tanstack/react-store@0.9.3` 硬依赖 `use-sync-external-store@1.6.0` polyfill，与 React 19 冲突
- 修复：在 `rsbuild.config.ts` 的 resolve.alias 中添加 `'use-sync-external-store': 'react'`
