## 渠道分析点击用户跳转数据看板 - username 参数修复 ✅

**问题**：渠道分析详情页点击用户后跳转到数据看板 `/console?username=xxx`，但 Dashboard 组件的 `useEffect` 依赖数组为空，导致导航后图表不会用新参数重新加载。

**修复内容**（`web/src/components/dashboard/index.jsx`）：

1. **useEffect 依赖修复**：`useEffect(() => { initChart(); }, [])` → `useEffect(() => { initChart(); }, [dashboardData.inputs.username])`
   - 当 URL 的 username 参数变化时，重新加载图表数据

2. **loadUserData 逻辑修复**：有 username 过滤时跳过用户排行数据加载
   - `if (dashboardData.isAdminUser)` → `if (dashboardData.isAdminUser && !dashboardData.inputs.username)`
   - 原因：`loadUserData` 调用 `/api/data/users` 返回所有用户的汇总数据，会覆盖已通过 username 过滤的单个用户图表数据

**完整数据流验证**：
- `Detail.jsx` → `navigate('/console?username=xxx')` ✅
- `useDashboardData` 从 URL 读取 username → `inputs.username` ✅
- `loadQuotaData` 调用 `/api/data/?username=xxx` ✅
- `model.GetAllQuotaDates` 按 username 过滤数据 ✅
- `initChart` 在 username 变化时重新执行 ✅
