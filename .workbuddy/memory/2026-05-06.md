## 修复测试模型时输入输出 token 为 0 的问题

- **根因**：`controller/channel-test.go` 的 `testChannel` 函数跳过了 `service.EstimateRequestToken`，导致 `info.GetEstimatePromptTokens()` 始终为 0。当上游 Provider 未返回 usage 信息时，fallback 到 0。
- **修复**：在调用 `ModelPriceHelper` 前补充 token 估算逻辑：
  ```go
  meta := request.GetTokenCountMeta()
  tokens, err := service.EstimateRequestToken(c, meta, info)
  if err != nil {
      common.SysError(fmt.Sprintf("testing channel %d estimate token error: %v", channel.Id, err))
  }
  info.SetEstimatePromptTokens(tokens)
  priceData, err := helper.ModelPriceHelper(c, info, tokens, meta)
  ```
- **修改文件**：`controller/channel-test.go`
- **linter 检查**：无新增报错
